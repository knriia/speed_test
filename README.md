# Замер скорости загрузки

Небольшой скрипт на Python измеряет скорость скачивания файла по прямой HTTP- или HTTPS-ссылке. Подойдёт, например, ссылка на большую картинку.

## Требования

- Python 3.10 или новее
- Дополнительные библиотеки не нужны

## Запуск скрипта

Выполняйте команды из корня проекта:

```bash
python main.py "https://example.org/path/to/large-image.jpg"
```

Передайте прямую ссылку на файл вместо примера выше. Можно задать тайм-аут одного запроса в секундах:

```bash
python main.py "https://example.org/path/to/large-image.jpg" --timeout 60
```

## Запуск тестов

Тесты используют стандартный `unittest` и не требуют установки дополнительных библиотек:

```bash
python -m unittest discover -s tests -v
```

По умолчанию скрипт делает **10 последовательных запросов**. Каждый ответ читается небольшими блоками и сразу отбрасывается: файл целиком в памяти не хранится и на диск не сохраняется. В конце печатаются число успешных запросов, суммарный объём данных, среднее время успешного запроса и средняя скорость загрузки.

Скорость считается как общий объём успешно скачанных данных, делённый на суммарное время успешных загрузок. МБ — десятичные мегабайты (1 МБ = 1 000 000 байт). Если запрос завершился ошибкой, скрипт сообщает об этом и продолжает оставшиеся запросы; при любой ошибке он завершится с ненулевым кодом.

## Пример вывода

```text
Сервер: example.org
Выполняю 10 последовательных запросов...

[1/10] скачано 5,242,880 байт за 1.231 с
...

Итог:
Успешных запросов: 10/10
Скачано всего: 52,428,800 байт (52.429 МБ)
Среднее время запроса: 1.231 с
Средняя скорость загрузки: 4.259 МБ/с
(1 МБ = 1 000 000 байт; скорость рассчитана по успешным запросам.)
```
